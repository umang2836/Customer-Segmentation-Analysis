# 📊 Customer Segmentation Analysis using K-Means

## Project Overview

This project performs customer segmentation using the K-Means clustering
algorithm. Customers are grouped based on purchasing behavior to help
businesses understand different customer segments and make data-driven
marketing decisions.

## Dataset

-   Mall Customers Dataset

## Project Workflow

-   Data Loading
-   Data Cleaning
-   Exploratory Data Analysis (EDA)
-   Feature Scaling
-   Elbow Method
-   K-Means Clustering
-   Cluster Visualization
-   Business Recommendations

## Technologies Used

-   Python
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Scikit-learn
-   Jupyter Notebook

## Machine Learning Algorithm

-   K-Means Clustering

## Evaluation

-   Elbow Method
-   Silhouette Score

## Business Recommendations

-   Reward premium customers with loyalty programs.
-   Offer discounts to budget-conscious customers.
-   Target potential customers with personalized marketing.
-   Design campaigns based on customer segments.
